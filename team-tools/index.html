Account Titling Reader

Upload a custodian statement or a trust, estate, POA or entity document. Claude pulls the registration, parties and beneficiaries so you can check them against the document and save them to the shared team log for account opening.

Open Account Titling Reader claude.ai/artifact/EzKQp67CxT81Gy7CAuCVdo

What it pulls

  • Exact account title, registration type, tax ID, trust name and date, governing state
  • Owners, grantors, trustees and successors, POA agents and signers
  • Primary and contingent beneficiaries, shares, per stirpes

Before a record is reviewed

  • Every flag needs a resolution note
  • Someone other than the person who saved it marks it reviewed
  • Name spellings and beneficiary totals are checked automatically

Reads PDF (text or scanned), Word .docx, images and pasted text. The file itself isn't saved, only the fields you approve. Seeing the team log requires Contributor access to the page.

Rep ID Search

Look up a Winthrop LPL / IFA Rep ID to see its advisors, primary point of contact and branch, or type an advisor's name to see every ID they're on. Answers come straight from the team's list, so a typo never returns a near match.

Open Rep ID Search claude.ai/artifact/GYQpQLpye6LxArj59zd1dW

Search by

  • Rep ID, such as L2MH
  • Advisor last name or nickname
  • Branch or manager ID, such as 50M6

Offices on the list

  • Winthrop Wealth (36HK)
  • Financial Planning Strategies (36HK)
  • Unified Wealth Management (K43N)
  • Keel Financial Partners (826X)

When a new "IFA REP IDs ACTIVE" PDF comes out, upload it under Keep the list current. You'll see every new, changed and missing ID before anything is saved.

ACAT Statement Reader

Upload a client's statement and Claude lists every account on it. The page then checks each account number, registration, value and position against the statement's own text, and flags anything that doesn't match or may not transfer.

Open ACAT Statement Reader claude.ai/artifact/9xnMsWPsfaK3anMkCpD1DU

For each account

  • Account number and registration exactly as printed, with copy buttons
  • Account type, transfer type and every position
  • Delivering firm, clearing firm and DTC number

Before it's ready

  • Tick each field once you've checked it against the statement
  • Write how each flag was resolved
  • Annuities, insurance and planning services are flagged as not moving by ACAT

DTC numbers come from the shared clearing firm table on the page. Most rows are still marked "Verify"; confirm each one from LPL's ACAT-eligible firm list before relying on it. The earlier prototype is still at claude.ai/artifact/VG32NWvCNwVpZuN1We62Qb.
