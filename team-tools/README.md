# Winthrop Team Tools

The hub page for the team's tools: one tab per tool with what it does, what it checks and a button that opens the live tool. Artifact pages can't embed each other, so each tool opens at its own address and keeps its own team log and access settings.

Live page: https://claude.ai/artifact/4uMuNaHSU17UCzxrNZUY6p (Claude artifact, shared with the organization)

## Tabs

- **All tools**: a row per tool with Details and Open, and the typical new-account flow.
- **Account Titling Reader**: https://claude.ai/artifact/EzKQp67CxT81Gy7CAuCVdo
- **Rep ID Search**: https://claude.ai/artifact/GYQpQLpye6LxArj59zd1dW
- **ACAT Statement Reader**: https://claude.ai/artifact/9xnMsWPsfaK3anMkCpD1DU

A tab can be linked to directly with `#titling`, `#repid` or `#acat`; the last tab opened is remembered per browser.

## Runtime

Static page, no capabilities. It stores nothing except the remembered tab in the viewer's own browser.

## Updating the live page

Edit `index.html`, then republish it to the artifact URL above from Claude Code.
